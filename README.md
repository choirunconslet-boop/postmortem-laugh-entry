A two-sentence postmortem of the silliest time an AI coding agent misunderstood a simple request and wrecked the code it was given. `main.py` writes the story to `/output/entry.txt`.

> I asked the agent to rename a single variable in the login handler. It renamed every 'user' across the whole repo instead — the database table, the API routes, and the error message, which now greets strangers with: 'Unknown usr, please log in again.'
